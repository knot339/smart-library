# ไฟล์เสียงพูดสำหรับหน้าการคืนหนังสือ (Tablet Return Page)

วางไฟล์เสียง `.mp3` ไว้ในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์ให้ตรงกับรายการด้านล่างเป๊ะๆ
(โค้ดจะเรียกเล่นที่ `/sounds/<ชื่อไฟล์>.mp3` โดยอัตโนมัติตามหน้าจอ/สถานะที่กำลังแสดง)

ถ้ายังไม่มีไฟล์ หรือไฟล์ชื่อไม่ตรง ระบบจะพูดด้วยเสียงสังเคราะห์ (Web Speech API ของเบราว์เซอร์) แทนไปก่อนโดยอัตโนมัติ
ไม่กระทบการใช้งาน แค่เสียงจะเป็นเสียงสังเคราะห์ ไม่ใช่เสียงอัดจริง

| ชื่อไฟล์ | เล่นตอน | ข้อความแนะนำ |
|---|---|---|
| `identify.mp3` | หน้าระบุตัวตน | ยินดีต้อนรับเข้าสู่ระบบคืนหนังสือ โปรดสแกนบัตรนักศึกษาหรือพิมพ์เบอร์โทร เพื่อดำเนินการต่อ |
| `check-book.mp3` | หน้าตรวจสอบหนังสือ | กรุณาวางหนังสือที่ต้องการคืนทีละหนึ่งเล่ม โดยนำสันหนังสือเข้าด้านใน |
| `drop.mp3` | หน้าดำเนินการคืนหนังสือเข้าตู้ | กรุณาตรวจสอบและยืนยันเพื่อดำเนินการคืนหนังสือ |
| `success.mp3` | หน้าคืนสำเร็จ | คืนหนังสือสำเร็จแล้วค่ะ ขอบคุณที่ใช้บริการ ผู้ใช้สามารถดำเนินการคืนเล่มถัดไปหรือเสร็จสิ้นการคืนได้เลยค่ะ |
| `not-found.mp3` | หน้าไม่พบหนังสือในระบบ | ขออภัยในความไม่สะดวก ไม่พบหนังสือในระบบค่ะ กรุณานำหนังสือไปติดต่อบรรณารักษ์ที่เคาน์เตอร์ |
| `cabinet-full.mp3` | หน้าตู้เต็ม | ขณะนี้ตู้รับคืนหนังสือเต็มแล้ว กรุณาติดต่อบรรณารักษ์ที่เคาน์เตอร์ |
| `identify-not-found.mp3` | หน้าระบุตัวตน ตอนกรอกรหัส/สแกนบัตรแล้วหาไม่พบ | ไม่พบรหัสผู้ใช้งาน กรุณาใส่เบอร์โทรหรือติดต่อบรรณารักษ์ที่เคาน์เตอร์ |

หน้าแรก (`select-user`) และหน้าอุปกรณ์ไม่พร้อมใช้งาน (ESP32 หลุดการเชื่อมต่อ) ไม่ต้องมีเสียงพูด

ข้อความด้านบนคือสิ่งที่พูดด้วยเสียงสังเคราะห์ ใช้เป็นสคริปต์อัดเสียงจริงได้เลย (จะเปลี่ยนคำพูดให้เป็นธรรมชาติขึ้นก็ได้ ไม่จำเป็นต้องตรงคำต่อคำ)
